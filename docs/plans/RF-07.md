## Reuse (do not reinvent)

- `docs/decisions.md` ya acumula los hallazgos de red y las direcciones; el README los referencia en vez de duplicarlos.
- La tabla de variables de entorno sale de `src/lib/chain/config.ts` (RF-01.2) — una sola fuente de verdad.
- Las capturas se toman del flujo real ya construido; no maquetar mockups.

## Out of scope

- Dominio propio (basta `*.vercel.app`).
- Analítica o tracking en la landing.
- Publicar el hilo de X y el mensaje en Telegram: la app entrega el borrador, publicarlo es acción humana.
- Traducción del README.

## Open risks

- **Dependemos de conseguir COOK real** para crear BAKE y hacer el airdrop (PRD §9, impacto Alto). Sin fondos no hay AC-07.3 ni AC-07.4 y la submission queda incompleta. Iniciar la gestión con el sponsor / el bridge **antes** de llegar a la fase 5, no al final.
- La CSP puede romper las imágenes de metadata remotas, que por diseño apuntan a dominios arbitrarios. Decidir explícitamente: `img-src https:` amplio, o proxy/bloqueo con placeholder. Anotar la decisión.
- Fecha de cierre ~22 sep 2026: RF-07 es lo último y lo que más se comprime. El token demo y las capturas pueden adelantarse en cuanto RF-03 esté verde.
